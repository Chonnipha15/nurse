ADMIN
‹ กลับหน้าร้าน
หน้านี้สำหรับผู้จัดทำ (Admin) เท่านั้น กรุณาเก็บลิงก์นี้ไว้เป็นส่วนตัว — ยังไม่มีระบบ Login ป้องกันการเข้าถึง (ตามสถาปัตยกรรมข้อ 40 ควรเพิ่มระบบ Authentication ก่อนใช้งานจริง) และไฟล์ที่แนบจะเก็บอยู่ในเบราว์เซอร์นี้เท่านั้น หากรีเฟรชหน้าจะหายไป แนะนำให้ "ดาวน์โหลดข้อมูลสินค้า" เก็บไว้ทุกครั้งที่แก้ไข

ยอดขาย

นำเข้าไฟล์ยอดขายที่บันทึกอัตโนมัติจากหน้าสั่งซื้อ หรือบันทึกเพิ่มด้วยมือ เพื่อดูยอดรายวันและสรุปรายเดือน

✅ เมื่อลูกค้าโอนเงินและกด "จำลอง: Admin ยืนยันการชำระเงิน" ในหน้าสั่งซื้อ ระบบจะบันทึกยอดขายให้อัตโนมัติในหน้านั้น — แต่เพราะหน้าสั่งซื้อกับหน้า Admin นี้เป็นคนละไฟล์ ไม่มี Backend เชื่อมกัน จึงต้องกดลิงก์ "สำหรับผู้ดูแลระบบ: ดาวน์โหลดข้อมูลยอดขาย" ที่ท้ายหน้าสั่งซื้อ แล้วนำไฟล์ JSON มา "นำเข้า" ที่นี่อีกที ไม่ต้องพิมพ์ยอดเองแล้ว (การนำเข้าจะรวมกับข้อมูลเดิม ไม่ทับรายการซ้ำ)
